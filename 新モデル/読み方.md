- results_*の中身

| ファイル名                            | 内容                  |
| -------------------------------- | ------------------- |
| `history_uniform.csv`            | 各反復でOE違反度がどう変化したか   |
| `profile_comparison_uniform.csv` | 762種類の選好ごとのRSDとの比較  |
| `solution_uniform.npz`           | 最終的な割り当て行列          |
| `summary_uniform.json`           | 最終OE違反度、耐戦略性の検証結果など |

- results_*/summary_*の読み方

| 変数名                    | 意味         |
| ---------------------- | ---------- |
| `initial_oe`           | 最適化前のOE違反度 |
| `final_oe`             | 最適化後のOE違反度 |
| `rsd_oe`               | RSDのOE違反度  |
| `improvement_over_rsd` | RSDからの改善量  |
| `beats_rsd`            | RSDより優れたか  |
| `exact_sp_violation`   | 耐戦略性の違反量   |
