- 新モデルに成功したコードを入れている

- 使用した主なライブラリ

| ライブラリ     | 主な役割        | コード内での用途                |
| --------- | ----------- | ----------------------- |
| SciPy     | 数値最適化・疎行列計算 | 線形計画問題（LP）の求解、SP制約行列の構築 |
| fractions | 有理数による厳密計算  | SP制約・等式制約の厳密な検証         |
| itertools | 順列・組合せの生成   | 選好プロファイル、エージェント・財の順列の列挙 |

- コードの構成
  - `matrix.py`：選好・対称性・制約行列・OE侵害度の構築
  - `main_*.py`：それぞれの初期値で最適化
 
- 圧縮・復元について
  - 匿名性・中立性を使い、331,776通りの選好を762種類の代表選好に圧縮
  - 人と財の置換を逆に適用し復元

- results_*の中身

| ファイル名                            | 内容                  |
| -------------------------------- | ------------------- |
| `history_uniform.csv`            | 各反復でOE違反度がどう変化したか   |
| `profile_comparison_uniform.csv` | 762種類の選好ごとのRSDとの比較  |
| `solution_uniform.npz`           | 最終的な割り当て行列          |
| `summary_uniform.json`           | 最終OE違反度、耐戦略性の検証結果など |

- results_*/summary_*の読み方

| 変数名                    | 意味         |
| ---------------------- | ---------- |
| `initial_oe`           | 最適化前のOE違反度 |
| `final_oe`             | 最適化後のOE違反度 |
| `rsd_oe`               | RSDのOE違反度  |
| `improvement_over_rsd` | RSDからの改善量  |
| `beats_rsd`            | RSDより優れたか  |
| `exact_sp_violation`   | 耐戦略性の違反量   |
